# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub instead:

1. Open the repository the problem is in.
2. Go to the **Security** tab.
3. Click **Report a vulnerability**.

Only the maintainers can see the report. We will reply there, and we will credit you when the fix
is published, unless you would rather stay anonymous.

Please include what you found, the steps to reproduce it, and what an attacker could do with it.

## What is covered

Every repository in the FactoryGameFan organization, and the sites they deploy, such as
<https://fbe.factorygamefan.com>.

We fix only the latest code on each repository's default branch. There are no older release lines
that receive security fixes.
